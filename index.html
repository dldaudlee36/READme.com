나만의 비공개 자리 (Passkey Vault)

비밀번호 없이 기기에서 생성된 비대칭 패스키로만 열 수 있는 보안 구역입니다.

🔑 패스키 인증 관리 센터

개인키는 기기 내부에만 보관되며, 서버에는 암호화된 공개키만 저장됩니다.

서버에 저장된 공개키(Public Key) 목록:
NETWORK AUTHENTICATION LOG STANDBY 
패스키 인증 요청 대기 중...
🔒 ACCESS GRANTED

나만 볼 수 있는 비공개 메모

[차기 개발 프로젝트 & 보안 아키텍처 구상안]

  • 무비밀번호(Passwordless) 고도화: FIDO2 / WebAuthn 하드웨어 토큰(YubiKey) 연동 연구
  • 개인키 유출 원천 방지: 디바이스 Secure Enclave(보안 영역) 내부 격리 서명 프로토콜 적용
  • 기기 분실 대비 복구 메커니즘: 서브 기기(스마트폰) 공개키 지문 대조를 통한 권한 회수 절차 확립

* 실제 연락처, 주민번호, 비밀번호 등의 민감 개인정보는 포함되어 있지 않습니다.
